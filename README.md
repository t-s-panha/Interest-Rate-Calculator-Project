# Interest Rate Calculator

A simple interest rate calculator project for the IBM Coursera specialization.

## Features
- Principal, Rate, and Years input
- Modern UI with responsive design
- Unit tests with Jasmine
- Bundled with Webpack

## How to Run

### 1. Open the Calculator
Simply open `index.html` in any web browser to use the calculator.

### 2. Run Unit Tests (Jasmine)
To run the automated tests, use the following command in your terminal:
```bash
npx jasmine
```

### 3. Build for Production (Webpack)
To bundle the project for distribution, run:
```bash
npx webpack
```
The output will be generated in the `dist/` folder.
